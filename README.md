# MLOps: пайплайн классификации Iris

Учебный проект с простым ML-пайплайном на **scikit-learn**: загрузка датасета Iris, подготовка выборок, обучение логистической регрессии и оценка качества модели.

## Установка

```bash
python3 -m venv .venv
source .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install -r requirements.txt
```

## Запуск

Все команды выполняйте **из корня проекта** (`mlops/`).

```bash
source .venv/bin/activate
python main.py
```
